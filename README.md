# 平衡感不好怎麼辦？4 招居家安全平衡感訓練

早安健康「居家平衡感訓練」動作影片圖解頁。四招動作各有一支 3D 示範影片（1:1、含語音解說與字幕），網頁上的步驟會跟著影片同步亮起，點步驟可直接跳到影片中的那一段。

1. 側單腳站立
2. 腳跟抵腳尖直線走
3. 後抬腿運動
4. 弓箭跨步

- 網址加上 `#1`～`#4` 可直接開啟某一招，例如 `index.html#3`
- 網址加上 `?embed` 為嵌入模式（精簡頁首、頁尾），適合用 iframe 放進文章

資料來源：梅約診所、克里夫蘭醫學中心、全民健康基金會、國健署。影片為動作示意，若有頭暈、關節疼痛或曾經跌倒，請先諮詢醫師或物理／職能治療師。
